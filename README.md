## 📌 Resumen del Proyecto
Análisis exploratorio, auditoría de calidad de datos y desarrollo de indicadores comerciales (KPIs) sobre un volumen transaccional de e-commerce.

### 🛠️ Herramientas Utilizadas
* **Google Sheets:** Limpieza, normalización, formulas `BUSCARV`, tablas dinámicas y análisis estadístico.
* **Google Docs:** Redacción del informe ejecutivo de calidad y caso de estudio.
* **Python / Pandas:** Verificación y validación de datasets.
